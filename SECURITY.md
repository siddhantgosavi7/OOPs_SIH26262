# Security Policy

This is a hackathon prototype that uses **synthetic data only**.

## Reporting a vulnerability
Report privately to `[TEAM CONTACT EMAIL]`. Do **not** open a public issue for a vulnerability, and do not include real personal data in any report. We aim to acknowledge reports within a few days.

## Scope
In scope: authentication, RBAC / region scoping, audit chain integrity, credential verification, file upload handling.
Out of scope: the real AICTE portal, NSWS or any government system (we do not integrate with them).

## Supported versions
Only the latest commit on `main`.

See `docs/SECURITY_AND_ISOLATION.md` and `docs/THREAT_MODEL.md` for design-level detail.
